# 🚀 AI Code Reviewer

An AI-powered full-stack web application that reviews source code and provides intelligent feedback on bugs, security flaws, performance issues, readability, and best practices.

Built using **React + Spring Boot + Groq LLM API**.

---

## ✨ Features

- 🔍 Detects runtime bugs and logic issues
- 🔐 Finds common security risks (SQL Injection, unsafe patterns)
- ⚡ Identifies performance bottlenecks
- 🧹 Suggests code improvements and refactoring ideas
- 📘 Language-aware best practices
- 🎯 Structured review output:
  - Issues Found
  - Improvements
  - Best Practices
  - Security Analysis
  - Quick Wins

## ⚙️ Run Locally

### 1️⃣ Clone Repo

```bash
git clone <your-repo-url>
cd AI-Code-Reviewer
````

### 2️⃣ Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```text
http://localhost:5173
```

### 3️⃣ Backend

Set environment variable:

```bash
GROQ_API_KEY=your_key
```

Then run Spring Boot app.

Runs on:

```text
http://localhost:8080
```
